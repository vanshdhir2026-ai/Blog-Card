### What I learned

In this project, I strengthened my core CSS skills by building a clean, centered card component. Here are the key technical concepts I practiced:

Flexbox & Centering: Learned how to use Flexbox (display: flex, justify-content: center, align-items: center) to place elements directly in the center of the screen both vertically and horizontally.

Responsive Design: Focused on layout responsiveness so the card adapts smoothly across different screen sizes.

Margin & Padding: Gained a better understanding of spatial layout—knowing exactly when to use padding (internal spacing) vs. margin (external spacing) for clean structure.

### Continued development

Moving forward, I am aiming to write cleaner, more efficient, and maintainable code. Specifically, my goals are:

Writing Efficient CSS: Avoiding redundant properties and unnecessary code overwriting to keep my stylesheet concise and readable.

Design Precision: Matching challenge designs pixel-for-pixel while using fewer total lines of code.

Mastering Responsiveness: Continuing to improve on layout responsiveness—turning a current weakness into a strong point through deeper practice with flexible units and media queries.

Building Good Habits: Reflecting on past errors to avoid repeating the same mistakes in future challenges.


### AI Collaboration

- During this project, I used Gemini as a learning assistant and debugging partner.
- When I got stuck trying to center elements vertically and horizontally, I asked Gemini for hints and code reviews to point out where my CSS layout was breaking.
- Rather than copying generated solutions, I used AI to understand why my code wasn't behaving as expected. I took those concepts and wrote all the actual code myself, ensuring I truly understood the principles behind centering and Flexbox.
